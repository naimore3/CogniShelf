## 1. 文档作用

本文件负责 F9 天文台楼层的场景、镜头、动效与验收细节；实现者与评审者使用；不负责总纲与滚动系统。

## 2. 描述范围

- IN：F9 天文台楼层的内部场景、镜头参数、层内动效、验收标准。
- OUT：首页总纲、左右分栏滚动系统、其他楼层细节（分别归上位设计与其他楼层子文档）。

## 3. 简略描述

F9 天文台是从屋顶露台下行后的第一站，一间向星空打开的夜观工作室：折射望远镜斜指开口上方，控制台与发光星图屏贴右后墙，中景浑仪式天球仪缓慢旋转，背墙是北斗星点连线，前景一张观测矮椅面向望远镜，红光暗适应灯是唯一持续呼吸的光点。道具全部用低面数几何拼装、哑光 toon 材质，亮色为纸白天文科教馆、暗色为深靛观星夜，两套只换色不换几何。

| 识别物 | 数量 | 画面作用 |
|---|---:|---|
| 折射望远镜 + 赤道仪脚架 | 1 | F9 首要轮廓，中后偏右、镜筒斜指开口上方 |
| 控制台 + 发光星图屏 | 1 组 | 主题锚点，贴右后角，青绿发光点缀 |
| 浑仪式天球仪 | 1 | 中景焦点，三环异速慢转 |
| 北斗星座背墙（点阵 + 连线） | 1 组 | 后景远景层次，不抢道具轮廓 |
| 观测矮椅 | 1 | 前景生活尺度，面向望远镜 |
| 红光暗适应灯 + 月盘 | 1 组 | 呼吸动效焦点与高处配平 |

## 4. 详细描述

### 4.1 本地坐标与镜头

组件挂在 `floor-registry.mjs` 的 F9 房间坐标下（`roomPosition(1)`），所有物体均使用房间本地坐标，不改动相机和房间链。房间尺寸 3.0 × 3.0 × 3.2（宽 × 深 × 高），原点在房间中心：地板顶面 `y = -1.36`，背墙内面 `z = -1.28`，右墙内面 `x = 1.28`。物体最高点控制在 `y = 1.2` 内，避免遮住相邻楼层。

镜头完全继承 `shared-room-camera`：hold 段机位固定在左顶角外侧向内看，不覆写 `camera`；F9 → F8 的 descend 走通用对角链路径，本层不覆写 `descend`。

| 参数 | 数值 | 验收口径 |
|---|---:|---|
| 望远镜脚架中心 | `(0.35, -1.36, -0.5)` | 三脚落地、不与控制台穿模 |
| 镜筒中心 / 仰角 | `(0.35, 0.1, -0.62)` / 38° | 筒尖约 `y = 0.75`，含寻星镜 `y ≤ 0.9`（硬上限 1.2） |
| 控制台中心 | `(0.96, -1.05, -1.02)`，台体 0.62 × 0.56 × 0.46 | 贴右后角，右缘 ≤ `x = 1.27` |
| 星图屏 | `(0.94, -0.66, -1.06)`，后倾约 12° | 从左顶角可直视、不被镜筒遮 |
| 天球仪环心 | `(-0.68, -0.6, -0.92)`，环半径 0.26 / 0.22 / 0.18 | 三环分离清晰，顶环 `y ≤ -0.3` |
| 观测椅 | `(-0.18, -1.36, 0.48)` | 前景可见、座面朝向望远镜 |
| 星座背墙 | 点位 `z = -1.26`，约 20 星点 + 北斗 7 点 6 连线 | 只作后景；避让楼层色条带 `y ∈ [0.71, 0.89] × x ∈ [-0.63, 0.63]` |
| 北斗七星区域 | 背墙左上 `x ∈ [-1.25, -0.55]`、`y ∈ [0.95, 1.35]` | 连线可辨、不与月盘重叠 |
| 月盘 | `(0.98, 1.02, -1.24)`，半径 0.15 | 高处配平，贴墙不悬空 |
| 红光灯 | `(1.08, -1.36, 0.3)`，灯头 `y ≈ -0.75` | 小面积红光，不照花星图屏 |
| 桌面小件 | 目镜盒 + 折叠星图，台面 `y ≈ -0.76` | 1–2 个体积，补生活尺度 |
| 动效 | 天球仪三环 0.12 / -0.09 / 0.06 rad/s、红灯颜色呼吸周期约 2.4 s、星图屏明度 ±8% | `prefers-reduced-motion` 下全部静止 |

### 4.2 材质与实现

- 低面数 `CylinderGeometry`（镜筒、脚架、灯杆）、`TorusGeometry`（天球仪三环、月盘光晕）、`BoxGeometry`（控制台、台面、椅、目镜盒）、`SphereGeometry`（镜身端盖、星点、灯头）组合道具，不加载外部模型或贴图。
- 道具统一用 `materials.toon()`，边缘用 `materials.line()`；`update(delta, tokens)` 先按 `tokens.scheme` 切换亮 / 暗两套糖果色（亮色：奶白镜筒 + 靛蓝脚架 + 青绿屏 + 金环；暗色：浅靛镜筒 + 中蓝脚架 + 亮青屏 + 亮金环），再叠加极小幅度动效。
- 星图屏与星点用高明度纯色 toon 面片模拟自发光，不加真实光源、不做 Bloom，符合「发光件只作小面积点缀」的哑光口径；星点共享一份球体几何，用 `InstancedMesh` 合并为 1 次 draw call，F9 单层 draw call 预算 ≤ 60。
- 模块契约与 F10 一致：`observatory.mjs` 导出 `createFloor(THREE, materials)`，返回 `{ group, update, dispose }`；只负责 F9 内部物体与销毁，不修改 `convenience-scene.mjs`、`floor-registry.mjs` 或滚动映射。
- 不使用 canvas 中文文字（本层无需任何文字贴图，规避中文字体缺字风险）；页面不可用 WebGL 时，既有 CSS 房间群继续提供可读降级，F9 的主题语义由右侧文案独立表达。

## 5. 难点

1. **细长镜筒在开口视角下易糊成杆件团**：望远镜是斜向细长体，若与控制台或背墙星点重叠，失败时 F9 只看到几根深色杆件，认不出天文台。
2. **3.0 × 3.0 小地面装不下「仪器感」**：望远镜、控制台、天球仪、椅子四件挤在一起会互相穿模或压住房间轮廓，失败时破坏房间链的清晰剪影。
3. **星空元素容易做过头**：背墙点阵太密会变噪点、发光太亮会抢右侧正文的注意力，失败时画面像撒了芝麻。
4. **亮暗双主题与降级**：暗色深紫舞台上深蓝道具会糊成一片；亮色下「夜观」语义可能立不住；无 WebGL 时只剩文案，主题识别缺失。
5. **动效与可访问性**：天球仪旋转、屏幕微闪若不停，会干扰 `prefers-reduced-motion` 用户。
6. **`prefers-reduced-motion` 下主题色不刷新**：单层调色板只在 rAF 循环内随 `interiors.update()` 刷新，reduce 模式下循环不启动，主题切换传不到楼层道具；失败现象是 reduce + 暗色时 F9 道具仍停在亮色（本轮已在框架侧修复，见解法 6）。

## 6. 解法

对应第 5 节逐条：

1. 望远镜放中后偏右 `(0.35, -1.36, -0.5)`、镜筒向后上方仰 38°，与背墙留出 ≥ 0.2 间隙；控制台、天球仪在 x 轴上分列 `0.96 / -0.68`，先保镜筒剪影再摆小件；逐项用左顶角机位截图检查开口取景。
2. 所有组件先在 3.0 × 3.0 × 3.2 盒体内布置：控制台贴右后角（右缘 ≤ 1.27）、天球仪靠左后、椅子与红灯在前景，最高点不超过 `y = 1.2`，不新增房间级几何；穿模检查以 4.1 坐标表逐行核对。
3. 星点约 20 颗、分两档大小（r 0.025 / 0.04），只集中在背墙上半区并避让楼层色条带；屏幕与星点用高明度小面片，亮度靠色相而非 Bloom；`InstancedMesh` 合并星点控制 draw call。
4. 道具底色保持中高明度（奶白、浅靛、中蓝）：`update()` 逐材质按 `scheme` 换色，暗色提高镜筒与星点明度、加深背景对比，亮色保留靛蓝主色与红光点，「科教馆白天也能认出是天文台」；无 WebGL 时星座几何语言与 CSS 房间群降级层同构，文案承担语义。
5. `update(delta)` 只保留三件极小动效（三环慢转、红灯 ±0.06 颜色呼吸、屏面 ±8% 明度）；入口侧由既有 reduced-motion 策略暂停循环，静止状态即完整构图。
6. 缺口已在框架侧落地：`interior-builder.mjs` 缓存最近一次 `tokens`，组件挂载完成后立即 `instance.update(0, lastTokens)`；`convenience-scene.mjs` 在场景初始化时播种一次 `interiors.update(0, tokens)`，并在 `themeObserver` 主题切换时补调一次——reduce 模式下挂载与换色都不再依赖 rAF 循环。验收：`prefers-reduced-motion: reduce` 下切换亮 / 暗各一次，F9 道具色随 token 同步变化且 Console 无报错。
