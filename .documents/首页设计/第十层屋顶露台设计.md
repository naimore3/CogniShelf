## 3. 简略描述

F10 是房间链顶端「向天空打开的日落露台」，做成一座**被浅镜池托起的漂浮日落花园**：

- **后景**：渐变日落穹幕（与背墙内面逐像素等大）+ 四层同心柔和日轮 + 三层城市剪影 + 星野 + 飞鸟剪影；
- **中景**：漂浮的胶木前岛（遮阳伞 + 双躺椅 + 边几）、紫调后岛（丛植 + 吧台车），两岛由四条支撑腿抬离水面，经踏步石相接；
- **前景**：浅镜池（后左缘接住落日余晖、前右缘沉成天顶紫）+ 池中浮光；
- **顶部**：纸灯笼串，左端系在伞杆上、右端挂在右墙内面挂钩上，两端都落在实处。

亮色是「纸白摄影棚里的午后日落花园」，暗色是「深紫舞台上的黄昏天光」；两套只换颜色与发光强度，不换几何、构图与镜头。

| 识别物 | 数量 | 画面作用 |
|---|---:|---|
| 渐变日落穹幕 | 1 | F10 的视觉背景与情绪主色 |
| 分层日轮（4 层同心辉光 + 10 根光芒） | 1 组 | 唯一高光点，压在地平线一带偏左 |
| 城市剪影（远/中/近三层 + 窗光） | 1 组 | 空气透视与远景层次 |
| 星野 / 云带 / 飞鸟剪影 | 3 组 | 天空的呼吸感，暗色下星野才点亮 |
| 浅镜池 + 池沿 + 池中浮光 | 1 组 | 前景分割，把地板变成「可照见天空」的水面 |
| 漂浮双岛 + 踏步石 | 1 组 | 中景舞台，纪念碑谷式连接 |
| 遮阳伞 / 躺椅 ×2 / 边几 | 4 | F10 首要轮廓 + 露台主题锚点 |

## 4. 详细描述

### 4.1 房间内表面与安全盒（硬约束，逐项实测确认）

组件挂在 `floor-registry.mjs` 的 F10 房间原点下（**世界坐标不是原点**：`getFloorPosition(10) = [13.5, 14.4, 0]`，由框架负责设置 `group.position`，本层只写房间本地坐标）。

| 参考面 | 数值 | 说明 |
|---|---:|---|
| 地板顶面 | `y = -1.36` | 所有落地物件基准面 |
| 背墙内面 | `z = -1.28` | 远景道具最多贴到 `z = -1.22` |
| 右墙内面 | `x = 1.28` | 道具右缘最多到 `x = 1.22` |
| 前开口下梁 / 立柱 | `z = 1.17 ~ 1.39`、`y = -1.35 ~ -1.13` | 低矮前景道具会被门框切一刀，故最前景只放水面与踏步石 |
| 左开口 | 无墙 | 前景负空间留给镜头 |

**统一安全盒**：`x ∈ [-1.22, 1.22]`、`z ∈ [-1.24, 1.22]`、`y ∈ [-1.36, 1.12]`。左墙不存在，取 `x ≥ -1.22` 只为与右墙对称、保持构图居中。

> 例外（有意为之）：渐变穹幕是 `3.00 × 3.20` 的平面，**故意与背墙内面逐像素等大**（`z = -1.273`，内面之前 0.007），因此它的 `x = ±1.50`、`y = ±1.60` 超出安全盒——这正是「天空就是这面墙本身」的做法，边缘与墙沿重合，不存在贴纸矩形边。v3.0 早先把穹幕退到墙后或放大到 6.00 × 4.60 都试过并否决：前者被实心背墙整片挡掉，后者从左开口伸出房间糊满画面。

### 4.2 风格定位

低面数几何 + 三渲二 toon + 糖果色哑光塑料 + 纪念碑谷式岛屿连接，**不是写实露台**。

| 维度 | 必须贴住的口径 |
|---|---|
| 造型 | 低面数、大块面；全部由 `BoxGeometry` / `CylinderGeometry` / `ConeGeometry` / `SphereGeometry` / `CircleGeometry` / `TorusGeometry` / `TubeGeometry` 缩放拼装，不加载外部模型与贴图 |
| 材质 | `MeshToonMaterial` + 库共享的 256×1 分档 `gradientMap` + `EdgesGeometry` 描边；哑光、低高光 |
| 发光 | 天空 / 日轮 / 灯珠 / 池水用 `MeshBasicMaterial`（`toneMapped: false`）或顶点色模拟自发光，**只用小面积点缀，不做 Bloom** |
| 灯光 | 完全沿用房间统一灯组，不另加光源；`castShadow` 由框架的 `enableShadows()` 在挂载时统一设置 |
| 镜头 | 完全交给 `camera-rig.mjs`；本层不碰相机、不碰滚动映射 |
| 动效 | 只有呼吸、漂浮、缓移三类极小幅度；`prefers-reduced-motion` 下全静止 |
| 构图 | 后景（穹幕/日轮/剪影）→ 中景（双岛/家具）→ 前景（镜池/踏步石）三层 |

### 4.3 与框架的契约

- 导出 `createFloor(THREE, materials)`，返回 `{ group, update, dispose }`；`group.name = "nmd-floor-roof"`；所有子物体只挂 `group`。
- 只读 `tokens.scheme` 与 `materials.toon()` / `materials.line()`，不写回材质库、不改框架其余文件。
- `update(delta, tokens)` 先 `applyTheme(tokens)`，再推进动效；**动效时间只由 `delta` 累积**（`step = delta > 0 && delta < 0.5 ? delta : 0`），不使用性能计时器，`delta = 0` 即自然停在首帧。
- `dispose()` 只释放本层自有的 geometry / 描边 geometry / 自建材质；库材质由库统一销毁，本层不重复 dispose。

### 4.4 材质与主题机制

- **`themeColorEntries`**：登记 `materials.toon()` 产出的材质，主题切换时**只改 `.color`**，不动材质库自身。
- **`ownedMaterials`**：本层自建的 `MeshBasicMaterial` / `PointsMaterial`，由本层 `dispose()` 释放。
- **`emissiveEntries`**：存 `[material, 亮色强度, 暗色强度]`，按主题重算自发光强度。
- **`edgeCache` + `edgeGeometries`**：`EdgesGeometry(geometry, 28)` 按源几何缓存，避免重复构建。

调色板 `PALETTE` 每项都是 `[亮色, 暗色]` 二元组，**只换颜色、不换几何与构图**：

### 4.5 布局要点

- **穹幕是唯一「超盒」元素**（见 4.1 例外），其余全部落在安全盒内，`bboxMax` 实测 `[1.45, 1.08, 1.22]`——`x = 1.45` 属穹幕。
- **镜池**：`POND_HALF = 1.03`、`POND_SIZE = 2.06`，水面 `y = -1.352`（地板顶面上方 0.008），前缘被门框下梁切出「一线池水」；四条池沿压在 `y = -1.352 + 0.012`。
- **双岛必须离地但有物理承接**：前岛与后岛各用四条支撑腿抬离水面（总纲禁止房间悬空），踏步石四块落在 `y = -1.345`。
- **画面右侧 = 房间 +x +z 象限（右前方）**：相机右向量 `(0.44, 0, 0.85)`，所以低矮盆栽放右后方只会缩在画面中部——压右侧空白必须把**竖向元素种在右前**（这就是新增 `buildTallPlant` 两组、且坐标取 `(0.94, -1.36, 0.80)` 与 `(1.00, -1.36, 0.14)` 的原因）。
- **灯串两端必须落在实处**：左端系伞杆、右端挂右墙挂钩，不允许悬空。
- **前开口下梁顶 = -1.38**（不是 -1.13）：`y = -1.38` 以下的前景道具才会被门框切，判断遮挡时按这个值算。

### 4.6 动效

三类，幅度都极小，全部由 `elapsed` 驱动：

| 类型 | 对象 | 幅度 |
|---|---|---|
| 呼吸 | 日轮内/外辉光、光芒、池中浮光 | `×(1 + sin(t·0.6~0.7)·0.035~0.14)` |
| 漂浮 | 前岛 / 后岛、灯珠 | 岛 `±0.014 / ±0.011`；灯珠 `±0.026` |
| 缓移 | 云带、飞鸟、伞面倾角 | 云 `sin(t·0.045)·0.10`；鸟 `((t·0.012 + 0.4) % 1.6) - 0.8`；伞 `0.05 + sin(t·0.5)·0.008` |

### 4.7 主题切换与降级

| 情形 | 表现 |
|---|---|
| 亮色（默认） | 纸白舞台 + 暖金/珊瑚/紫/天顶蓝的日落渐变；整体明亮、哑光 |
| 暗色 | 深紫舞台 + 深蓝/紫/珊瑚/金天空；**星野点亮**（opacity 0.16 → 0.92）、日轮与灯珠增强、池水提亮 |

| WebGL 不可用 | 由框架 CSS 降级层承担；F10 主题语义由右侧文案独立表达 |
| `navigation.instant` | 滑出 ±1 窗口即 `unmount()` → `dispose()`；实测本层 21 个自有 geometry 全部释放、无泄漏 |

## 5. 难点

1. **背景极易做成「贴纸」**：背墙只有 3.0 × 3.2，一旦做成矩形色块，上沿与左右边都会露出来，立刻变成一张贴在墙上的画。
2. **径向渐变不能靠贴图**：v3.0 早先用纯色 `CircleGeometry` 叠三层做日轮，结果是三个同心硬边圆，画面读成一个「拱门」轮廓。
3. **顶点色方案会连带影响别的物件**：给材质开 `vertexColors` 后，凡是复用该材质的几何体必须自己带 `color` 属性，否则 attribute 未绑定会读成黑色。
4. **小房间塞太多物件**：伞、两椅、水、台、八组植物、灯串若都堆在前景会穿模或压掉房间轮廓。
5. **镜头是固定的左顶角**：所有道具共享一条斜向视线，遮挡必须在布局阶段解决，不能靠转镜头。
6. **安全盒很窄**：`x ≤ 1.22`、`z ≤ 1.22`、`y ≤ 1.12`，一个「大概放得下」的手感往往会超 0.03 ~ 0.05 而不自知。
7. **移动端画布不是整屏高**：`homepage.css:232` 在 `max-width: 1023px` 下把场景列设为 `55vh`，440 × 880 视口的真实画布是 440 × 484。
8. **验证链路本身会骗人**：出图夹具若漏掉阴影 traverse、或没摘掉框架的半透明占位盒，看到的画面根本不是线上画面。

## 6. 解法

1. **穹幕 = 背墙本身**：把渐变平面做到与背墙内面逐像素等大、贴在 `z = -1.273`，边缘与墙沿重合，于是「天空」就是这面墙，矩形边消失；渐变按**顶点真实高度**取值（`raw = (y - skyBottom) / SKY_H`，`t = clamp(raw) ** 1.35`），段数一改也不会整体错位。
2. **日轮改用径向渐变圆盘**：新增 `makeGlowDiscGeometry(segments)`——三角扇，中心顶点 `color = [1,1,1,1]`、圆周顶点 `color = [1,1,1,0]`，用 **4 分量顶点色做柔边**（three.js 在 `color.itemSize === 4` 时启用 `vertexAlphas`，不需要贴图也不需要 Bloom）；四层同心叠出柔和辉光，再用橙色 `sunRayMaterial` 单画 10 根光芒。
3. **需要顶点色的东西各自拿材质**：光芒不能复用开了 `vertexColors` 的日轮材质（`unitBox` 没有 `color` 属性 → 会变黑），必须单独拆一份材质。
4. **按视线顺序分层并收敛**：后景只放天空类元素，中景只放双岛与家具，前景只放水面与踏步石；遮挡优先级固定为「伞面 → 椅头 → 池面高光 → 日轮」，逐项截图核对。
5. **用探针代替手感**：预览页临时把 `group.position` 归零，遍历本层子物体算 `bboxMin` / `bboxMax`，并按 `maxY` / `maxZ` 降序点名越界网格（不再手算）。实测这一步抓出了三处越界：水面满铺到 `z = 1.30`、右前丛叶 `z = 1.247`、伞顶金珠 `y = 1.165`（原注释漏算珠半径）。
6. **移动端按真实画布出图**：440 × 484，而不是 440 × 880。
7. **夹具与真实链路对齐**：出图前必须补 `interior-builder.mjs:14-21` 的同款 `enableShadows()` traverse，并摘掉 `scene-builder.mjs:134-141` 的半透明占位盒；否则阴影全缺、整张图被灰盒糊住。详见 `.documents/阶段截图/README.md`。
8. **右侧空白用竖向元素压**：先算出相机右向量对应「房间右前方」，再在那里种两组高杆绿植，而不是往右后方堆矮盆栽。

### 7.1 非本层职责的遗留观察（须单独处理，不在此次范围内）

1. **`materials.mjs:28-38` 的 `toon()` 无缓存**：每次都把新材质 push 进库级数组，而 `interior-builder.mjs:47` 卸载时只调单层 `instance.dispose()` → 每次滚动重挂载都会新增约 20+ 个永不释放的库级 `MeshToonMaterial`（缓慢泄漏）。注意**不能简单按颜色缓存**：本层会改这些材质的 `.color`，按颜色缓存会别名互踩。
2. **前右门框立柱的 shadow acne / z-fighting 条纹**：属 `scene-builder.mjs` 的门框几何自阴影，暗色下尤其明显。
3. **背墙紫色 `accent` 条**（`scene-builder.mjs:129-132`）：11 层共有，在日落背景上偏突兀，但目标是楼层识别色，未动。
4. **`convenience-scene.mjs` 在沙箱里不评估**：MathJax 是阻塞解析的经典脚本，其 CDN 下载不完成时 `DOMContentLoaded` 不触发，而 `type="module"` 的场景入口是 deferred → 整站停在 CSS 降级层。已用 HEAD 版对照实验证明与本次改动无关，出图时用 `CDP_BLOCK_URLS` 屏蔽 CDN 规避。
