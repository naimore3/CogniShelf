## 1. 文档作用

本文件负责 F10 屋顶露台楼层的场景、镜头、动效与验收细节；实现者与评审者使用；不负责总纲与滚动系统。本次 v2.0 是对 v1.0 的**重设计**：把原来散点摆放、物件靠墙穿模、背景只有栏杆的“色块感露台”，改为**带日落天空幕布、前后岛屿、浅水镜面、遮阳伞与躺椅的“漂浮日落花园”**。

## 2. 描述范围

## 3. 简略描述

F10 是房间链顶端“向天空打开的日落露台”。它不追求写实楼顶，而是做成一座**被浅水镜面切开的前后两个低台**：前岛放遮阳伞与两张沙滩椅，后侧是落日天空幕布、城市天际线剪影与高矮绿植；一条踏步石小路跨过水面把两岛接起来，右上角挂一组漂浮小灯。所有物件统一为低面数几何 + 哑光 toon 材质 + 描边，亮色是“午后纸白摄影棚里的日落花园”，暗色是“深紫舞台上的黄昏天光”。

**本次重设计主要改四件事**：

1. 增加一层**日落天空幕布**（四段水平色带 + 落日圆盘 + 城市剪影），把原来空白的背墙变成有纵深和情绪的远景。
2. 把原来容易穿墙、贴在背墙/右墙上的物件全部收回安全区，用**前景水面、中景低台、背景天空**三层构图重新布局。
3. 收敛物件：**伞、椅、水、台、灯、植**各司其职，不堆道具、不互相遮挡，优先保证轮廓可辨。
4. 明确“怎么嵌合进房间”：统一使用房间本地坐标、尺寸盒与安全边距，给出可照抄的摆放区间与验收口径。

| 识别物 | 数量 | 画面作用 |
|---|---:|---|
| 日落天空幕布 + 落日 | 1 组 | F10 的视觉背景与情绪主色 |
| 遮阳伞 | 1 | F10 首要轮廓，位于前岛左中 |
| 沙滩躺椅 | 2 | 露台主题锚点，橙 / 紫互补 |
| 浅水镜面 + 踏步石 | 1 组 | 把前岛与后岛分成两个只在角部/石路相连的岛 |
| 绿植盆栽 | 3 | 左、右、后三处高低错落，提供生活尺度 |
| 吧台车 + 杯具 | 1 组 | 前景可读的微缩道具 |
| 漂浮小灯串 | 1 组 | 顶部轮廓与黄昏氛围 |
| 城市天际线剪影 | 1 组 | 远景层次，不抢道具轮廓 |

## 4. 详细描述

### 4.1 本地坐标、房间内表面与安全区

组件挂在 `floor-registry.mjs` 的 F10 房间坐标下，所有物体均使用房间本地坐标，不改动相机和房间链。房间尺寸为 **3.0（宽）× 3.2（高）× 3.0（深）**，原点在房间中心。本次以实际框架为准，给出内部可用面：

| 参考面 | 数值 | 说明 |
|---|---:|---|
| 地板顶面 | `y = -1.36` | 所有落地物件以此为基准面 |
| 背墙内面 | `z = -1.28` | 远景道具最多贴到 `z = -1.22` |
| 右墙内面 | `x = 1.28` | 道具右缘最多到 `x = 1.22` |
| 前开口 | `z ≈ +1.39` 处为门框立柱 | 前景道具保持 `z ≤ 1.22` |
| 左开口 | 左侧无墙 | 前景负空间留给镜头 |
| 物件高度上限 | `y ≤ 1.12`（硬上限 1.2） | 不遮挡相邻楼层、不顶到门框上梁 |

**统一安全盒**：所有 F10 物件放进 `x ∈ [-1.22, 1.22]`、`z ∈ [-1.22, 1.22]`、`y ∈ [-1.36, 1.12]` 的盒体内；贴墙道具再额外留 0.06–0.10 的间隙，避免描边或阴影穿进墙内。

```

  ┌─────────────────────────────────────────┐
  │ 天空幕布：深蓝 -> 紫 -> 珊瑚 -> 金       │  右墙
  │        [城市剪影]        [落日]          │  x = +1.28
  │                                          │
  │  P1 高棕榈                   岛B + P2    │
  │        [遮阳伞]                            │
  │        [椅1] [椅2]                         │
  │   ~~~~ 浅水镜面 ~~~~   [吧台车]          │
  │   P3 低盆栽    [踏步石]                  │
  └─────────────────────────────────────────┘
                   前开口 (z = +1.39)
                   镜头从左顶角看向房间中心
```

### 4.2 风格定位

F10 是“低面数几何 + 三渲二 toon + 糖果色哑光塑料 + 纪念碑谷式岛屿连接”的**微缩日落花园**，不是写实露台。

| 维度 | 必须贴住的口径 |
|---|---|
| 造型 | 低面数、大块面、圆角/倒角感；不加载外部模型或贴图 |
| 材质 | `MeshToonMaterial` + 256×1 分档 `gradientMap` + `EdgesGeometry` 描边；哑光、低高光 |
| 色彩 | 1 个主题主色（珊瑚橙）+ 2 个辅助色（金、青）；天空背景用四段邻近色过渡 |
| 灯光 | 沿用房间统一灯组，不另加真实点光源；天空幕布用高明度面片模拟“自发光”，不做 Bloom |
| 动效 | 只有水镜缓转、漂浮灯上下、伞绳微摆三类极小动效；`prefers-reduced-motion` 下全静止 |
| 构图 | 前中后三层：水镜（前景）→ 低台与家具（中景）→ 天空幕布与剪影（后景） |

### 4.4 实现方法

**模块契约**：`roof-terrace.mjs` 导出 `createFloor(THREE, materials)`，返回 `{ group, update, dispose }`。`group.name = "nmd-floor-roof"`，所有子物体只挂到 `group`，不修改 `convenience-scene.mjs`、`floor-registry.mjs` 或滚动映射。

**几何与材质**：

- 复用 `BoxGeometry`、`CylinderGeometry`、`ConeGeometry`、`SphereGeometry`、`TorusGeometry`、`CircleGeometry`、`TubeGeometry`，不加载外部模型或贴图。
- 实体道具统一 `materials.toon()`，边缘用 `materials.line()`；天空幕布用不透明白色/高明度色带，不做透明渐变。
- 浅水镜面用 `materials.toon("#56c8d8", { transparent: true, opacity: 0.82 })`；如需要环形池边，可加 `RingGeometry` 或八边形 `TorusGeometry`。
- 天空幕布、落日、灯珠用高明度纯色面片模拟“自发光”，不加真实光源、不做 Bloom，符合总纲「发光件只作小面积点缀」。
- 落日圆盘用 `CircleGeometry`（默认法线朝 +z，正好面向镜头）或压扁的 `SphereGeometry`，避免普通球体在侧视时太鼓。

**调色板（亮 / 暗两套）**：`update(delta, tokens)` 根据 `tokens.scheme` 切换，与既有 `--nmd-floor-roof` accent 联动。

| 用途 | 亮色 | 暗色 |
|---|---|---|
| 遮阳伞 / 躺椅主色 | `#f97316` | `#ff9b62` |
| 躺椅辅助色 | `#7656b8` | `#b26bff` |
| 天空顶部 | `#8fb8e8` | `#28345f` |
| 天空中段 | `#c7a3f0` | `#59418f` |
| 天空珊瑚段 | `#f4a58b` | `#b6536f` |
| 天空近地面 | `#ffd98f` | `#e2a04a` |
| 落日 / 灯珠 | `#ffd166` | `#ffc75a` |
| 水面 | `#56c8d8` | `#33e3f1` |
| 陶土 / 树干 | `#d97758` | `#b86b67` |
| 叶片 | `#4f9d69` / `#8bcf8a` | `#6bbf86` / `#a5e09a` |
| 描边 | `#30264f`，opacity 0.36 | 同左 |

**更新与销毁**：

- `update(delta, tokens)`：先按 `tokens.scheme` 换色，再叠加极小动效；水面 `rotation.z += delta * 0.035`，漂浮灯 `y = 基线 + sin(t + phase) * 0.06`，灯串或伞面只做幅度极小的位移动画。
- 几何体集中数组，`dispose()` 中逐一 `geometry.dispose()`；描边 `LineSegments` 的几何也要 `dispose()`；材质由库统一管理，不在单层 `dispose()` 里重复销毁库材质。
- 不使用 canvas 中文文字；页面不可用 WebGL 时，既有 CSS 房间群继续提供可读降级，F10 的主题语义由右侧文案独立表达。

### 4.5 怎么嵌合进房间内

1. **只使用房间本地坐标**：`group` 挂在注册表提供的 F10 房间原点下，所有位置都不写世界坐标，不复制房间几何。
2. **落地基准**：地面物件以 `y = -1.36` 为基准；前岛木台、后岛花台刻意抬高约 0.11，保留“漂浮岛”语义，但不悬空成明显断线。
3. **贴墙余量**：天空幕布贴到 `z = -1.23`，落日到 `z = -1.20`，均比背墙内面 `z = -1.28` 提前 0.05–0.08，避免被墙吃掉；右侧花台与盆栽右缘控制在 `x ≤ 1.22`，不穿右墙。
4. **前景让位**：浅水镜面和踏步石放在 `x` 负半区与 `z` 正半区（靠近镜头、靠左），把前开口的负空间留给镜头；吧台车放在前右，不越过 `z = 1.22`。
5. **遮挡优先级**：伞面 → 椅子头 → 水镜高光 → 落日，按这一顺序逐项截图；任何一项被挡，先移动伞/椅，再动背景，不改动相机或房间。
6. **验收方式**：在 `shared-room-camera` 的 hold 段机位下，F10 当前房间占画面高度 60–70%；落日、伞面、两张椅背、水镜边缘全部可见；邻房只露一个角。

### 4.6 如何美化

1. **背景分层**：把空背墙换成天空幕布，四段邻近色从深蓝过渡到金，配合落日和城市剪影，先让房间有“纵深感”再摆道具。
2. **前景分割**：浅水镜面不是纯装饰，它把地面切成两个岛，配合踏步石让空间有“可走进去”的路径，而不是一张平铺地板。
3. **主次分明**：伞是唯一大轮廓，躺椅是第二层，杯具、灯珠、叶片是第三层；道具少而有焦点，避免每个物体同等重要。
4. **颜色收敛**：全层只允许珊瑚橙 + 金 + 青三个强调色，其余用奶白、陶土、紫灰压底；高饱和颜色集中在伞、落日、水面上。
5. **剪影清晰**：用描边把椅背、伞面、花盆轮廓勾出来；从镜头方向看，每个物件都要能靠剪影认出，不靠贴图解释。
6. **发光与动效做点缀**：灯珠、落日、水面只作小面积亮点，动效只做呼吸和慢转；不做整层闪动、不遮挡右侧正文。
7. **留白**：房间外保留安静舞台负空间，道具不顶满画幅；当前房间占画面高度约 65%，而不是撑满。
8. **双主题一致**：亮色是纸白舞台里的下午花园，暗色是深紫舞台上的黄昏；两套只换颜色和灯光强度，不换几何、不换镜头。

### 4.7 主题切换与降级

| 情形 | 表现 |
|---|---|
| 亮色（默认） | 纸白舞台 + 浅蓝/珊瑚/金天空幕布；整体明亮、哑光 |
| 暗色 | 深紫舞台 + 深蓝/紫/珊瑚/金天空；灯珠与水面更亮，形成黄昏发光点 |
| `prefers-reduced-motion: reduce` | 水镜、灯串、伞面动效全部静止；首帧就使用当前主题调色板，不等 rAF 循环 |
| WebGL 不可用 | 显示既有 CSS 房间群降级层；F10 主题语义由右侧文案承担 |
| `navigation.instant` | 离开首页时 `dispose()` 完整销毁几何与描边，无内存泄漏 |

## 5. 难点

1. **开口视角容易遮挡**：伞面、椅背、落日、水镜高光都处在同一条斜向视线里，一旦重叠，F10 会退化成“几块色板”。
2. **小房间容易装下太多物件**：伞、两椅、水、台、三盆植物、灯串若都堆在前景，会互相穿模或压到房间轮廓。
3. **天空幕布容易做得像贴纸**：如果只是整面纯色墙，就会失去“天空”的情绪；如果色带太碎，又会变成噪点。
4. **贴墙道具容易穿墙**：背墙内面只有 `z = -1.28`、右墙内面只有 `x = 1.28`，物件稍大就会穿进墙里或从外侧露出一半。
5. **浅水镜面的透明排序**：透明水面与描边、踏步石、地板之间的渲染顺序若处理不当，会出现水面吞掉踏板或高光闪断。
6. **亮暗双主题与降级**：暗色深紫舞台上深蓝道具会糊成一片；无 WebGL 时只剩文案，主题识别缺失；reduced-motion 下动效循环可能不启动，导致主题色不刷新。

## 6. 解法

对应第 5 节逐条：

1. **按视线顺序分层**：先摆背景（天空、落日、天际线），再摆中景（伞、椅、岛台），最后摆前景（水镜、踏步石、吧台车）；用 4.5 的遮挡优先级逐项截图，先动伞椅再动背景。
2. **收敛物件到 11 组并分区**：前景只放水镜、踏步石、吧台车；中景只放前岛、伞、两椅；后景只放天空、落日、剪影和靠后盆栽；不把生活小件全塞进前岛。
3. **天空幕布用四段邻近色 + 一个落日 + 少量天际线**：色带宽度相等、颜色相邻，太阳和剪影提供焦点，避免纯色墙或碎色带。
4. **所有物件放进 4.1 的安全盒**：右缘 `≤ 1.22`、后缘 `≥ -1.22`、高度 `≤ 1.12`；坐标表逐行核对，贴墙道具额外留 0.06–0.10 间隙。
5. **透明水面优先**：水面使用 `depthWrite: false`、`transparent: true`，放在前景且 `renderOrder` 靠后；踏步石和池边用不透明实体先画，水面后画；如仍有闪断，缩小水面或把踏步石抬到水面之上 0.03。
6. **双主题与降级**：`update(delta, tokens)` 首帧就按 `tokens.scheme` 换色；`interior-builder.mjs` 已在挂载与主题切换时补调 `instance.update(0, tokens)`，reduced-motion 下不依赖 rAF；暗色提高伞/落日/水面明度、压暗天空顶部，亮色保留珊瑚与金作为识别点；无 WebGL 时由右侧文案独立表达主题。
