## 3. 简略描述

**风格定调**：F10 要做成一只**被柔光打亮的屋顶花园玩具**——哑光塑料质感、全部圆角、面上明暗连续过渡、**没有描边**、没有画上去的天空；结构件是奶油白，靠一个大色块墙面、一个对比色块地面和 2–3 个高饱和道具色撑起画面，房间外就是暗色舞台的负空间。

**和现状的根本差别**：现在是「三渲二 toon 分档 + 黑色描边 + 画在背墙上的紫色日落幕布 + 11 组小道具塞满房间」；目标是「平滑材质连续明暗 + 无描边 + 不画天空 + 6–8 组大件道具 + 等距俯视留白」。这是两套互斥的风格系统，**靠调参调不过去**。

| 识别物 | 数量 | 画面作用 |
|---|---|---|
| 背墙大色块（暖珊瑚，房间壳） | 1 | 舞台主色块，靠主光自然形成从亮到暗的大跨度渐变 |
| 奶油白结构：护栏带 / 花箱 / 伞骨 / 椅架 | 1 组 | 全部结构的统一色，充当画面留白 |
| 木地板 + 薄荷青水台 | 2 块 | 地面两级色块；水台是画面第二个视觉锚（对应参考图地毯的位置关系） |
| 遮阳伞（珊瑚橙伞面 + 奶油白伞骨） | 1 | 首要轮廓与主题锚点 |
| 沙滩椅 / 躺椅 ×2 + 边几 | 3 | 主题锚点「沙滩椅」，也是中景的水平线 |
| 大型多肉 / 仙人掌 + 圆叶盆栽 ×3 + 高杆绿植 ×1 | 5 | 「一圈错落的绿植」，兼压住画面右侧空白 |
| 背墙矮花箱 | 1 | 后带水平线，把背墙大色块"收边" |
| 纸灯笼串 | 1 | 顶部轮廓与暖光点 |

亮色 = 纸白摄影台上的同一只玩具（`--nmd-stage: #f4effa`）；暗色 = 深靛紫舞台上的同一只玩具（`--nmd-stage: #160f2b`）——**暗色那一态才是参考图的舞台关系**，亮色只把舞台翻白，几何、材质、镜头、色块关系完全一致。

### 4.2 风格 DNA（六条，验收时逐条勾选）

| # | 口径 | 可核对的表现 |
|---|---|---|
| 1 | **无描边、连续明暗** | 场景里不出现任何 `EdgesGeometry` / `LineBasicMaterial` 描边；面与面的交界只由色差和阴影区分；同一面上明暗连续 |
| 2 | **全圆角** | 所有箱体的可见棱都有倒角，圆角半径约为该件最短边的 5%；没有任何一条裸露的 90° 硬边（房间壳的边框、地板也包在内） |
| 3 | **哑光塑料** | `metalness = 0`、`roughness ≈ 0.35–0.55`、无任何贴图、无做旧；只有玻璃杯/灯芯等少数小件带微弱镜面 |
| 4 | **大柔光 + 强环境填充** | 一束方向明确的大面积主光 + 高比例环境光；暗部不纯黑、不死黑；每个落地件都有柔和的接触阴影把它"钉"在地面上；阴影本身是灰紫色而非黑色 |
| 5 | **高饱和色块 + 奶油白结构 + 深色舞台** | 墙面一个大色块、地面一个对比色块、结构全部奶油白；高饱和点缀色最多 3 种，只给体积较大的道具；房间外是暗色负空间 |
| 6 | **等距俯视 + 大留白** | 俯角约 30°、方位角约 45°、长焦压缩透视；当前房间占画面高 60–70%；道具少而大，地面留空，房间四周留舞台负空间 |

### 4.4 房间、开口与安全盒

沿用框架既有几何，本版不动这些数值：

| 参考面 | 数值 | 说明 |
|---|---:|---|
| 地板顶面 | `y = -1.36` | 所有落地物件的基准面 |
| 背墙内面 | `z = -1.28` | 道具最多贴到 `z = -1.22` |
| 右墙内面 | `x = 1.28` | 道具右缘最多到 `x = 1.22` |
| 开口 | 顶面 / 正面 / 左侧 | 保留地板、背墙、右墙 |
| 安全盒 | `x ∈ [-1.22, 1.22]`、`z ∈ [-1.24, 1.22]`、`y ∈ [-1.36, 1.12]` | 唯一例外见下 |

- **取消 v3.0 的"超盒天空穹幕"**：新风格不画天空，房间外直接是舞台负空间，所以不再需要任何超出安全盒的对象（安全盒从此没有例外项，验收时 `bbox` 必须完全落在盒内）。
- 房间壳自身圆角（见 4.3 第 2 条）：外框 `r ≈ 0.045`、地板四角 `r ≈ 0.06`；圆角在壳内部完成，不改房间尺寸与链式相接关系。
- **两面可见墙在画面上的分工**（由 4.3 第 5 条的新机位算出，相机右向量 `(0.707, 0, 0.707)`）：**背墙占画面左半边，右墙占画面右半边，两面墙的公共竖棱落在画面横向中线附近**。所以「靠墙的大件」放背墙沿线（画面左/中），「压画面右侧」放右墙沿线与房间 +x+z 近角一侧。
- 地板四周留白：地板平面本身不铺满色块，水台色块四周至少留 0.30 的裸木地板，避免地面又被色块占满。

### 4.6 几何规约

1. **所有箱体走圆角箱**：`roundedBox(w, h, d, r, seg)`，`r = clamp(0.05 × min(w, h, d), 0.02, 0.09)`、`seg = 3`。
2. **圆角箱配方**（`RoundedBoxGeometry` 未被 vendor，见第 5 节难点 2）：

   ```text
   Shape  = 宽 w-2r、高 h-2r、圆角 r 的圆角矩形
   Geometry = ExtrudeGeometry(Shape, {
     depth: d - 2r, bevelEnabled: true,
     bevelThickness: r, bevelSize: r, bevelSegments: 2, curveSegments: 3
   })
   Geometry.center(); Geometry.computeVertexNormals()
   ```

   按 `(w,h,d,r)` 缓存，`dispose()` 时统一释放。不要靠"单位圆角箱 + 非等比缩放"省几何——非等比缩放会把圆角压成椭圆角，一眼露怯。
3. **有机形体**用 `CapsuleGeometry`（核心已有）+ `SphereGeometry` 直接穿插拼接，不做布尔运算：仙人掌 = 3–5 根胶囊；叶片 = 压扁的球/胶囊；灯笼 = 胶囊。
4. **厚度下限**：任何可见构件的最短边 ≥ 0.05，避免薄片读成"纸片"。
5. **道具概括到 2–4 个体积**：参考图里连街机、桌面显示器、镜头都只有几个大块，不刻小细节（按键就是几颗球，轮子就是几个圆柱）。
6. **预算**：单层 geometry ≤ 60、三角形 ≤ 60k、draw call ≤ 220。圆角箱的 `bevelSegments 2 / curveSegments 3` 是上限，不得再抬。

| 类别 | 材质 | 参数 |
|---|---|---|
| 哑光塑料（房间壳、家具、伞面、花箱） | `MeshStandardMaterial` | `metalness 0`、`roughness 0.42`、`envMapIntensity 0.30`、`flatShading false` |
| 软胶（仙人掌、叶片、坐垫、灯笼） | `MeshStandardMaterial` | `metalness 0`、`roughness 0.62`、`envMapIntensity 0.35` |
| 微亮塑料（杯具、灯芯外壳、伞顶珠） | `MeshPhysicalMaterial` | `metalness 0`、`roughness 0.18`、`clearcoat 0.6`、`clearcoatRoughness 0.25` |
| 自发光（灯笼暖芯） | `MeshStandardMaterial` | `emissive` 按主题取色、`emissiveIntensity ≈ 1.2` |
| 地面 / 水台 | `MeshStandardMaterial` | `roughness 0.5` / `0.25`（水台略亮，靠环境贴图反出柔和反光） |
| 接触阴影贴片 | `MeshBasicMaterial` | `vertexColors: true`（4 分量顶点色做柔边）、`transparent`、`depthWrite false`、`toneMapped false` |

**禁止**：`MeshToonMaterial`、`gradientMap`、`EdgesGeometry`、`LineBasicMaterial` 描边、任何贴图（`renderer.info.memory.textures` 应为 0，仅剩环境贴图与库共享资源）。自发光不做 Bloom（vendor 无 postprocessing），只靠色值和面积控制。

### 4.8 光照规约

| 项 | 规约 |
|---|---|
| 主光 key | 大面积方向光（或 `angle ≥ 1.0 / penumbra 1 / decay 0` 的聚光），自画面左后上方来，色温偏暖（亮色 `#fff2e2`，暗色 `#ffd9a8`）；墙面最亮点与最暗点亮度差约 1.6 倍，且**渐变必须是连续的** |
| 环境光 | `HemisphereLight` 强度占主导（sky 冷青紫 / ground 暖珊瑚），负责把暗部抬起来；房间内最暗像素亮度不低于整体的 25% |
| 补光 fill | 低强度冷色（亮色 `#cfe0ff`）自右前方补，压住暗部的暖色偏移；不允许在墙上打出可见光斑边界 |
| 阴影 | 只给体积 ≥ 0.12 的道具开 `castShadow`；`mapSize 2048`、`radius 4`、`VSMShadowMap`；阴影最深处不低于 18% 亮度，**禁止纯黑** |
| 接触阴影贴片（必需） | 每个落地件在 `y = 地板顶 + 0.002` 放一块软边圆片（`CircleGeometry` + 4 分量顶点色：中心 alpha 0.35 → 边缘 0），半径 = 道具水平外接半径 × 1.15。**这是落地感的主手段**，因为 `convenience-scene.mjs:99-106` 的 `qualityProfile()` 在移动端/低性能设备上会整体关掉 `shadowMap`——真实阴影那时全部消失，只有贴片还能把物件钉在地上 |
| 环境贴图 | `scene.environment` 由 4.3 第 4 条的手搓 `PMREMGenerator.fromScene()` 提供；本层不自建 envMap，也不 dispose 它 |

### 4.11 动效

五类，幅度都极小，全部由 `elapsed` 累积（`step = delta > 0 && delta < 0.5 ? delta : 0`）：

| 类型 | 对象 | 幅度 | 周期 |
|---|---|---|---|
| 呼吸 | 灯笼暖芯 `emissiveIntensity` | ×(1 + sin(t·0.9)·0.06) | ≈ 7.0 s |
| 缓摆 | 整串灯笼绕两端连线 | 绕 x 轴 ±0.9° | ≈ 6.5 s |
| 缓摆 | 伞面 | 绕 z 轴 ±0.7° | ≈ 8.0 s |
| 漂浮 | 水台碎光片 | 位置 ±0.02、透明度 ×(1 ± 0.10) | ≈ 5.5 s |
| 微动 | 叶片 | 绕 y 轴 ±1.2° | ≈ 9.0 s |

`prefers-reduced-motion: reduce` → `delta` 传 0 → `elapsed` 不推进，画面停在首帧；首帧即用当前主题色板，不等 rAF 循环。

### 4.12 亮暗主题与降级

| 情形 | 表现 |
|---|---|
| 亮色（默认） | 纸白舞台（`--nmd-stage: #f4effa`）+ 高饱和色块房间，像放在白色取样台上的玩具；阴影浅灰、通透 |
| 暗色 | 深靛紫舞台（`--nmd-stage: #160f2b`）+ 暖主光 + 紫环境光 + 灯笼自发光增强；**这一态就是参考图的舞台关系** |
| `prefers-reduced-motion: reduce` | 同 4.11：画面停首帧，首帧即正确主题 |
| WebGL 不可用 | 由框架 CSS 降级层承担；F10 的主题语义由右侧文案独立表达 |
| 移动端 / 低性能（`shadowMap` 被关） | 真实阴影全部消失，落地感完全由 4.8 的接触阴影贴片承担；本项必须在手机上单独验收 |
| `navigation.instant` | 滑出 ±1 窗口即 `unmount()` → `dispose()`；本层自有 geometry 与自建材质全部释放，无泄漏 |

### 4.13 与框架的契约

- 导出 `createFloor(THREE, materials)`，返回 `{ group, update, dispose }`；`group.name = "nmd-floor-roof"`；所有子物体只挂 `group`（挂载位置由 `interior-builder.mjs:45` 设为房间世界原点，本层只写房间本地坐标）。
- **不再调用 `materials.toon()` / `materials.line()`**（4.3 后这两个函数在场景里退役）；本层自建 `MeshStandardMaterial` / `MeshPhysicalMaterial` / `MeshBasicMaterial`，全部登记进本层 `ownedMaterials`，由本层 `dispose()` 释放，**不写回材质库**。
- 需要随主题换色的材质登记进 `themeColorEntries`，主题切换**只改 `.color`（及自发光强度）**，不动几何与构图。
- `update(delta, tokens)` 先 `applyTheme(tokens)`，再推进动效。
- `dispose()` 释放：本层全部 geometry（含按尺寸缓存的圆角箱）、自建材质、自建贴片；**不 dispose** 库材质、共享 `gradientMap`、以及 4.3 第 4 条建立的共享 `scene.environment`。

## 5. 难点

1. **风格跨越材质层，本层改不动**：质感由框架建的房间壳材质与灯组决定；只改本层会出现"道具平滑了、墙还是分档的"半吊子画面。
2. **`RoundedBoxGeometry` 不在 vendor 里**：`docs/javascripts/three/examples/jsm/` 下只有 `controls` / `objects` / `utils` 三个目录（无 `geometries`），不自己造圆角箱就只能用硬边箱——而硬边一眼读成"低模方块"，不是"塑料玩具"。
3. **没有后期处理可用**：vendor 无 `postprocessing`，拿不到 SSAO / Bloom / 景深；物件容易"浮在面上"，发光件也糊不出光晕。
4. **移动端会关阴影**：`convenience-scene.mjs:99-106` 的 `qualityProfile()` 在粗指针或窄屏下把 `renderer.shadowMap.enabled` 置 false，真实阴影全无，物件会像贴纸一样飘。
5. **高饱和色块互相打架**：高饱和用得越多越乱，画面会从"设计过的玩具"退化成"翻倒的玩具箱"。
6. **改机位会外溢到全站**：`ROOM_CAMERA` 是 11 层共用的，单独为 F10 抬头会破坏链的取景一致性。
7. **塑料感依赖环境贴图**：没有 envMap 的 `MeshStandardMaterial` 会读成粉笔/石膏，哑光塑料的"半透感"主要来自环境反射。
8. **色板极易滑回"雾紫灰"**：`--nmd-room-wall` 这类现成 token 的明度偏低，直接沿用就会回到现在的观感。

## 6. 解法

1. **先做框架风格底座，再重写本层**：按第 9 节 S1 → S2 → S3 的顺序推进；本层只负责造型与摆放，材质/灯光/相机的口径在框架层统一。
2. **自建 `roundedBox()`**：`ExtrudeGeometry(圆角矩形, { depth, bevelEnabled, bevelThickness: r, bevelSize: r })`（4.6 配方），按 `(w,h,d,r)` 缓存 geometry，`dispose()` 统一释放。**备选方案**：把官方 MIT 的 `RoundedBoxGeometry.js`（同版本 three@0.160.0）单文件放进 vendor 的 `examples/jsm/geometries/`——同一库同一版本、不引入新依赖，但会动 vendor 目录，需上位规范确认；默认走自建方案。
3. **手搓环境贴图代替后期**：`PMREMGenerator.fromScene(envScene)` 造 envMap（核心 API，无需 addon），配合 `metalness 0 + envMapIntensity 0.30` 出哑光塑料感；发光件只调 `emissiveIntensity` 与面积，不追求光晕。
4. **接触阴影贴片当主手段**：4 分量顶点色软边圆片（复用 v3.0 已在用的顶点色柔边技巧）+ 真实阴影贴图作为加分项；这样**纹理化阴影开关关闭的移动端也能落地**。
5. **色板守卫**：固定「1 墙主色块 + 1 地对比色块 + 奶油白结构 + 至多 3 个点缀色」；点缀色只给体积 ≥ 0.3 的道具；验收脚本按 4.5 的色值抽样比对，偏离即判不通过。
6. **机位改造与 S1 合并成一次全站切换**：`ROOM_CAMERA` 一次改完，用 4.9 的五个可测指标验收（像素量取），不凭手感。
7. **envMap 不足时的退路**：先把 `envMapIntensity` 提到 0.7、`roughness` 降到 0.35；仍不足则把背墙明度再抬 6%，但**不允许**用增加光源数量来救。
8. **色板来源固定**：新色值全部写进本文档第 4.5 节与 `homepage.css` 的 `--nmd-*` token（亮暗两套并行），禁止在代码里散落魔法色值。

### 11.4 安全盒（修订口径）

v3.0 的「所有物体必须落在 x ∈ [-1.22,1.22] / z ∈ [-1.24,1.22] / y ∈ [-1.36,1.12]」是为**独立道具**定的。v4.0 增加了三类**贴面构件**，它们应当贴到房间壳内面，故按下表分档：

| 类别 | 允许范围 | 实测 |
| --- | --- | --- |
| 独立道具（家具 / 花盆 / 伞 / 边几） | `x ∈ [-1.22,1.22]`、`z ∈ [-1.24,1.22]`、`y ≤ 1.12` | 最高件为灯笼串末端 y 0.87；躺椅后缘 z 1.19 |

### 11.6 本层的防泄漏契约（其他楼层照抄）

模块级 `const bundleCache = new WeakMap()`，键为材质库实例，值是该库共享的一套本层材质。理由：`materials.plastic()` 会把材质 push 进**库级数组**且只在库 `dispose()` 时释放，若每次 `createFloor` 都新建材质，随滚动反复重挂载会线性泄漏。因此：

- 材质**只能**由库释放，楼层组件**不得** dispose 自己用到的库材质；
- 本层只释放自己造的几何（`owned[]`）；实测 `dispose()` 前 143 个几何 → 后 6 个（剩下的 6 个属于房间壳），`geometryFreed = 137 / owned = 137`，textures 无自有项。
